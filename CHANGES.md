# Change log

## 1.0.0-beta.1 - 2026-10-07

- Renamed the plugin to Video Checkpoint with the unique component `mod_videocheckpoint`.
- Added Moodle-uploaded MP4 and Vimeo playback.
- Added timed multiple-choice checkpoints with correct and incorrect feedback.
- Added server-side watched-interval tracking, gradebook integration and custom completion.
- Added optional AI-assisted draft-question generation through Moodle's AI subsystem.
- Added backup, restore and Privacy API support.
